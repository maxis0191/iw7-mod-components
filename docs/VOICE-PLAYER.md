IW7 Zombies voice - quick setup

1. Close the game and extract IW7-Zombies-Voice.zip.
2. Copy its contents into your game folder, next to iw7_ship.exe.
3. Double-click Start-IW7-Zombies-Voice.bat. Join the same compatible server
   as your friend and enable voice in the game settings.

The current player executable also supports a direct double-click with no
arguments. Custom shortcuts with arguments must include -iw7-voice-relay.

Use your voice key to talk. Test both directions, then mute/unmute and reconnect.
Your usual iw7-mod.exe launcher and saves are preserved.

If you cannot hear each other, both players can enter voice_relay_status in the
console. gate=ready confirms the voice connection; a roster containing only
your own slot means your friend has not joined voice yet. The status explains
disabled launch options, loading/session gates and negotiation separately.

Windows 10/11 x64; an existing Infinite Warfare installation is required.
Both players and the server need compatible voice builds. This is a beta.

Developers: matching code is in IW7-Zombies-Voice-Source.zip, supplied alongside
the player download. It is not needed to install or play.
